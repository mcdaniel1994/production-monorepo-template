# Completed Build Specifications

Implemented and frozen specifications live here as historical records of what was requested and how
completion was judged.

A specification enters this directory only after implementation and verification are complete. In
the same change, give it the terminal implementation stamp, move it from `../active/`, remove its
active queue row, and update direct links. After that move, do not edit or rename it; changed intent
gets a new numbered specification.

If this README is the directory's only file, the project has no completed specifications yet.
